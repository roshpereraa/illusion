# Illusion

Marketing site for **Illusion**, an immersive 3D & interactive design studio.

Built with Vite, Three.js, GSAP ScrollTrigger and Lenis. All artwork is generated in code (WebGL scenes, shaders and SVG).

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # outputs to dist/
```

Pages: `index.html` (home), `about.html`, `projects.html`.
